操作体験：Xプロフィール文を3案作る

使う場面
最初の操作体験。コピー → 貼り付け → 送信の練習と、Geminiが動くかの確認
書き換え
不要。そのまま送信してください
あなたはSNSマーケティングの専門家です。
宇都宮市で営業する個人経営のカフェの、X（旧Twitter）のプロフィール文を3案作ってください。

【背景】
・店主1人と、アルバイト2人の小さな店
・自家焙煎のコーヒーと、栃木県産のいちごを使ったスイーツが看板商品
・近所に住む30〜50代の方に「どんな店か」「何が自慢か」が10秒で伝わる文章にしたい

【制約】
・各案は120文字以内
・絵文字は1つまで
・専門用語を使わない
・3案は切り口を変える（親しみやすさ／こだわり／お得な情報）

【出力形式】
案1〜案3を番号付きで。各案の下に「ねらい」を1行添えてください。
役割・背景・制約・出力形式の4つがそろった「指示の型」です

SNS運用方針プロンプト

使う場面
演習1。新しいチャットを開いて、最初に貼り付けます
書き換え
冒頭の【記入欄】8項目。ワークシート1に書いた内容を写します
出力
「SNS運用方針」シートと同じ項目順の表。そのままシートに転記できます

書き換えるのは【ここに記入】の部分だけです。分からない項目は空欄のままで構いません。AIが最大3つ質問してから作ります。

あなたは宇都宮市の小規模事業者を支援するチーフSNSマネージャーです。
以下の【記入欄】の情報をもとに、「SNS運用方針」シートを埋めるための内容を作ってください。1日30分で続けられる運用を前提にします。

【記入欄】（分かる範囲で書いてください。空欄があれば質問してください）
・屋号・ブランド名：【ここに記入】
・業種：【ここに記入】
・主な商品・サービス：【ここに記入】
・SNSで実現したいこと（来店／予約／採用／ネット販売など）：【ここに記入】
・来てほしいお客様（年代・住まい・興味など）：【ここに記入】
・自社の強み（他店との違い）：【ここに記入】
・今使っているSNS、または使えそうなSNS：【ここに記入】
・1日にSNSに使える時間：【ここに記入】分

【進め方】
1. 記入欄に空欄があれば、最大3つまで質問してください。回答がなければ合理的に仮定し、冒頭に「仮定一覧」として示してください。
2. 質問が不要なら、すぐに作ってください。

【出力形式】次の順番と項目名を変えずに、「項目／内容」の2列の表で出力してください。内容は各項目1〜3行に収めます。

■ SNS運用方針
1. 運用目的とKPI
　目的／KPI／達成期間
2. メインターゲット（来てほしいお客様1人を具体的に）
　名前（仮名）／年代・性別／家族構成／職業／居住地／興味・関心
3. 利用メディア
　SNS名（主軸1つ＋補完1つ。X、Instagram、LINE公式アカウント、Facebook、TikTok、YouTube、Googleビジネスプロフィールから、理由付きで）
　ベンチマークアカウント（参考にする同業アカウントの探し方。実在を確認できないアカウント名は書かない）
4. キャラクター設定（投稿する「中の人」の人物像。架空でよい）
　名前／性別／生年月日／家族構成／出身／趣味・嗜好／口調
5. 投稿方針
　投稿頻度（1日に使える時間で続けられる回数と時間帯）
　投稿内容（投稿の柱3〜5本と、それぞれのテーマ例）
　リプライへの反応／他アカウントへの反応／ハッシュタグの活用／フォロー方針
　目標達成に向けたKPI（到達＝インプレッション、交流＝エンゲージメント、フォロワーの3つで月間目標）
　対象外アカウント（フォローや反応をしない相手）

■ コンテンツ案
No.1〜6のタイトルを表で（投稿の柱からバランスよく）

■ ハッシュタグ候補
10個（#宇都宮 などの地域タグを2つ以上含める）

【制約】
・日本語で、専門用語には短い説明を添える
・KPIは「まず3か月で達成できる」控えめな数字にする
・ツールの料金や仕様は「要公式確認」と注記する
・お客様の個人情報、実在の個人の情報は扱わない
出力の表を、ワークシート2「SNS運用方針」またはExcelのD列に転記します
  • 出力が途中で止まったら「続けて」と送ってください。
  • 表が崩れたら「表の部分だけ、もう一度作り直して」と送ってください。
  • 直したい項目があれば「投稿頻度を週2回にして作り直して」のように、項目名を指定して頼んでください。

実績振り返りプロンプト（運用1か月後に）

使う場面
セミナーでは使いません。1か月運用したあと、月1回の振り返りに
書き換え
【記入欄】4項目と、実績データの貼り付け（Xの「アナリティクス」やInstagramの「インサイト」の数字、または画面の写真）

数字をそろえるのが大変なときは、Xのアナリティクス画面やInstagramのインサイト画面のスクリーンショットを添付して「この画像から読み取って」と添えるだけでも動きます。

あなたは宇都宮市の小規模事業者を支援するチーフSNSマネージャーです。
以下の投稿実績をもとに、来月の改善点を優先順位付きで提案してください。

【記入欄】
・SNSの種類：【ここに記入】
・集計期間（例：2026年11月1日〜30日）：【ここに記入】
・SNSの目的（例：来店促進）：【ここに記入】
・今月の投稿本数：【ここに記入】本

【実績データ】（下に貼り付けるか、画面の写真を添付してください）
【ここに貼り付け】
例：投稿日／本文の冒頭／インプレッション／いいね／保存／返信／プロフィール閲覧

【評価のしかた】
・到達（インプレッション）、交流（いいね・保存・返信・リポスト）、行動（プロフィール閲覧・リンククリック・来店）の3段階で見る
・反応が良かった投稿と伸びなかった投稿を3本ずつ挙げ、共通点を説明する
・データが少ない場合や極端な値がある場合は、その旨を注記する
・画像から読み取った数字には、確からしさ（高／中／低）を添える

【出力形式】
1. 今月のまとめ（3行）
2. 良かった投稿・伸びなかった投稿（表）
3. 来月の改善アクション（優先度 高・中・低で3〜5個）
4. 投稿の柱の見直し案
5. 来月のKPI目標（到達・交流・行動）
11/24のInstagram編でも、この振り返りの考え方を使います

Geminiに入力してはいけない情報

  • お客様の氏名・住所・電話番号・メールアドレスなどの個人情報
  • 未公開の売上や取引先の情報、社内だけの資料
  • パスワードや口座番号

入力した内容はGoogleの学習に使われる場合があります。業種や商品の特徴など、公開して困らない情報だけを使ってください。

このプロンプト集は、本日の受講者の方が自社のSNS運用のために自由にお使いいただけます。ChatGPTなど他の生成AIにも、そのまま貼り付けて使えます。
